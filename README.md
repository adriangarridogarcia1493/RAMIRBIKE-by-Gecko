# Ramirbike by Gecko 🦎🚲

## Descripció del projecte

Ramirbike by Gecko és un videojoc desenvolupat amb HTML, CSS i JavaScript.

El jugador controla una bicicleta que ha d'esquivar obstacles, recollir monedes i aconseguir la màxima distància possible. El joc inclou diferents mons, sistema de nivells, mode infinit, botiga de bicicletes, ruleta de premis i diversos minijocs.

## Objectius

* Aprendre programació web.
* Desenvolupar un videojoc interactiu.
* Aplicar HTML, CSS i JavaScript en un projecte complet.
* Gestionar el desenvolupament mitjançant GitHub.
